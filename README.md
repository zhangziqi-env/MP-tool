## English

I work with microplastic samples and microscopy images. **MP Label-V1** is my first small software project; more practical tools for the microplastics workflow are on the way.

### Featured project: MP Label-V1

A local Windows application for annotating microplastic particles in microscopy images.

- Mark particles with type, judgment, colour and remark
- Rectangle / polygon lasso batch annotation
- Depth grouping and ID management
- Excel statistics and Word reports with full-resolution images
- English and Chinese versions, fully offline

[View MP Label-V1](https://github.com/<your-name>/MP-Label-V1)

### What's next

I plan to publish a series of small tools around the microplastics workflow, for example:

- image annotation and particle measurement
- data cleaning and statistics
- report generation and repetitive lab tasks

If you work with microplastics and have a repetitive task that could be simplified, feel free to open an issue in the project repository.
