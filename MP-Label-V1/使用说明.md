# MP Label-V1 使用说明

本说明对应打包好的 `MP Label-V1.exe` / `MP Label-V1_中文版.exe`，以及 Python 源码 `MP Label-V1.py` / `MP Label-V1_中文版.py`。

> English version: [User-Guide-EN.md](User-Guide-EN.md)

## 设计初衷

MP Label-V1 是围绕真实的显微观察流程设计的，不只是“在图片上画点”。

1. **给所有样品留下完整照片记录。** 一次把样品拍完，图片就是可以长期保存、复查和分享的原始记录；以后不需要为了核对信息再把切片放回显微镜。
2. **把显微镜时间用在真正需要的地方。** 拍照必须使用显微镜；标注、分类、比较和导出都可以之后在普通电脑上完成，显微镜不必被整理记录的工作占着。
3. **备注主要用于记录微塑料种类。** 备注首先是写微塑料类别/种类，以及一两条方便后续识别的短说明；写法统一，导出的表格才容易分组和筛选。
4. **快速分类未知颗粒。** 标记/截图的主要目的是先快速分类。同一种未知颗粒在一个样品里出现很多次（例如同一形态出现 10 次）时，扫描过程中先把这些位置标出来；之后导出 Excel/Word，对照位置和备注，从中选一个代表去做 FTIR/Raman 或其他确认检测，通常不需要 10 个都测。

简单说：一次拍照留存，离线标注分类，备注写清种类，再借导出记录决定哪些代表颗粒值得花时间做确认检测。

## 0. 启动方式

本发布包提供 4 个程序文件，按“语言 + 使用方式”选择：

| 下载 | 语言 | 适合谁 | 需要 Python |
| --- | --- | --- | --- |
| `MP Label-V1.exe` | 英文 | 直接双击使用 | 不需要 |
| `MP Label-V1_中文版.exe` | 中文 | 直接双击使用 | 不需要 |
| `MP Label-V1.py` | 英文 | 想自己运行/修改源码 | 需要 |
| `MP Label-V1_中文版.py` | 中文 | 想自己运行/修改源码 | 需要 |

### 方式一：单文件 exe（推荐给最终用户）

1. 下载对应语言的 exe（英文 `MP Label-V1.exe` / 中文 `MP Label-V1_中文版.exe`）；
2. 放到一个**可写的文件夹**（例如桌面、下载目录；不要放 `C:\Program Files`）；
3. 双击运行。

说明：

- 这是完整的单文件程序，已包含 Tcl/Tk 界面库和 python-docx 模板，**不需要安装 Python，也不需要额外的 `_internal` 文件夹**。
- 启动时会在 exe 同目录临时解压 `_MEI...`，正常关闭会自动删除；如果程序被强制结束，可能留下一个 `_MEI...` 目录，手动删除即可。
- 如果 Windows 提示“未知发布者”，选择“更多信息 → 仍要运行”（程序未签名）。
- 如果公司电脑的安全策略禁止在本地目录解压，改用下面的 Python 源码方式。

### 方式二：Python 源码

1. 下载对应语言的源码：英文 `MP Label-V1.py`，中文 `MP Label-V1_中文版.py`；
2. 安装依赖并运行：

```bat
python -m pip install -r requirements.txt
python "MP Label-V1.py"
:: 中文版
python "MP Label-V1_中文版.py"
```

要求：Windows 10/11、Python 3.10+，并安装了包含 Tcl/Tk 的标准 Python（python.org 安装包默认包含）。


## 1. 界面概览

主窗口从上到下是四排工具栏：

1. **图片与文件**：Add、Delete、Prev、Next、Save、Clear、Undo、Redo、Reset View、Open Proj、Save Proj。
2. **模式**：Annotation Mode、Rectangle Lasso、Polygon Lasso。
3. **深度与编号**：Depth、Renumber、Continue Num、Delete ID、Edit Remark、Edit Colour。
4. **导出**：Excel Detail、Excel Stats、Word Report(All)、Word Export Test。

中文版对应按钮为：添加、删除、上一张、下一张、保存、清空、撤销、重做、重置视图、打开工程、保存工程、标注模式、矩形套索、多边形套索、深度、重新编号、继续编号、删除编号、编辑备注、编辑颜色、Excel 明细、Excel 统计、Word 报告（全部）、Word 按判断导出。

> 类型名（fibre/film/...）、判断（MP/NoMP/Test）、Test 子类型（label/unlabel）在中文版中仍保留英文，以保证中英文工程和导出数据互通；颜色名、按钮、提示和表头会翻译成中文。

底部状态栏显示当前图片、深度和总图片数；画布会提示当前模式与鼠标操作。标注、批量、编号/备注/颜色编辑和导出选择等弹窗会显示在屏幕中央。

## 2. 添加图片与设置深度

1. 点 **Add**，选择一张或多张图片。支持 `jpg`、`jpeg`、`png`、`bmp`、`tif`、`tiff`。
2. 用 **Prev / Next** 切换图片。
3. 点 **Depth**，输入当前图片的深度（例如 `0–1 cm`、`10–11 cm`）。同一深度下的所有图片共享编号空间。

> 建议深度写法统一（分隔符、空格一致），这样 Excel/Word 才不会把 `10cm` 和 `10 cm` 分成两组。

## 3. 单张标注

在 **Annotation Mode** 下：

- **左键点击**颗粒位置，弹出对话框：
  - Type：`fibre`、`film`、`fragment`、`foram`、`bead`、`pellet`、`custom`；
  - Judgment：`MP`、`NoMP`、`Test`；
  - 选 `Test` 时可再选 `label` / `unlabel`；
  - **Colour（颜色）**：`透明 / 白色 / 黑色 / 蓝色 / 红色 / 黄色 / 绿色 / 棕色 / 灰色 / 其他`，可选“不设置”；
  - **Remark（备注）**：主要填写微塑料类别/种类，以及一小段方便后续识别的说明。
- **Ctrl + 左键**点击已有标注附近，删除该标注（命中半径随缩放自动调整）。
- 标注 ID 在当前深度内自动递增；切换到同深度其他图片会继续使用同一个 ID 序列。
- 添加后可用 **Edit Colour / 编辑颜色** 输入 ID 修改颜色，或用 **Edit Remark / 编辑备注** 修改备注。

### 记录重复出现的未知颗粒

这个工具是为了快速分类，而不是要求当场把每个颗粒都鉴定出来。

1. 同一种未知形态反复出现时，扫描过程中把每次出现（或至少把代表位置）都标出来。
2. 给这一组统一填写 Type/Remark，例如临时写 `unknown-A`，后续筛选更容易。
3. 导出 **Excel Detail** / **Word Report(All)**，按类型/备注列对照这些位置，再选择一个代表去做确认检测。
4. 如果需要给报告或讨论留视觉记录，点 **Save** 保存带标注 PNG；ID、坐标和备注仍保留在工程和导出结果里。

这样既不会拖慢第一遍扫描，又为“后面挑谁去检测”保留了足够信息。

## 4. 矩形/多边形套索批量标注

### 矩形套索

1. 点 **Rectangle Lasso**；
2. 在画布上按住左键拖出矩形，松开；
3. 在弹窗中填写数量、类型、判断、Test 子类型、颜色、备注；
4. 点 **Add Annotations**。

程序会在矩形内随机生成指定数量的标注点，并把该区域保存到“套索区域”列表，供 **Word Export Test** 使用。

### 多边形套索

1. 点 **Polygon Lasso**；
2. 左键依次点击多边形顶点；
3. 右键完成；
4. 在弹窗中填写数量、类型、判断、Test 子类型、颜色、备注；
5. 点 **Add Annotations and Save Area**。

如果多边形太小或形状很细，可能无法找到足够多的随机点，程序会提示实际生成数量。

> 套索区域与“当前图片 + 深度”绑定：修改深度会同步更新区域深度；清空标注或删除图片会同步删除对应区域。

## 5. 编号与备注管理

- **Renumber**：把当前深度下所有图片的标注按“图片路径 → 原顺序”重新编号为 1..N，并同步更新备注键。
- **Continue Num**：只查看当前深度的最大 ID 和下一个可用 ID，不修改数据。
- **Delete ID**：输入 ID 删除当前图片上的标注。
- **Edit Remark**：输入 ID 修改备注/子类型；留空会删除备注。
- **Edit Colour**：输入 ID 修改颗粒颜色；选“不设置”可清除颜色。
- **Clear**：清空当前图片全部标注（和该图的套索区域）。
- **Undo / Redo**：50 步；覆盖标注、颜色、深度、备注、套索、删除图片等。Renumber 可以正常撤销。

## 6. 缩放与查看

- **滚轮**缩放，缩放中心跟随鼠标。
- **中键拖动**平移。
- **Reset View**：图片适配窗口。
- 缩放到较小比例时只显示 ID，避免文字重叠；放大后显示类型/判断、颜色和备注。

## 7. 保存图片与工程

### 保存带标注的 PNG

点 **Save**（或 `Ctrl+Shift+S`）：把当前标注直接画到原图上，保存为同目录下的 `<原文件名>_annotated.png`（保持原分辨率）。

保存后会询问是否把这张带标注图加入当前列表继续编辑：
- 默认 **No**，只保存 PNG；
- 选 Yes 会作为独立图片加入，使用新 ID、复制备注/颜色，并提示会重复计入导出统计。

### 工程文件

- **Save Proj**（`Ctrl+S`）：保存 `.json` 工程，包含图片路径、深度、标注、颜色、备注、套索区域和当前索引；不包含图片文件本身。
- **Open Proj**（`Ctrl+O`）：打开工程；若当前有未保存修改会先确认。
- 自动保存：`%LOCALAPPDATA%\ENVer\autosave.json`；异常关闭后下次启动会询问是否恢复。
- 错误日志：`%LOCALAPPDATA%\ENVer\error.log`。

> 工程里保存的是图片的绝对路径。换电脑或移动图片目录后，打开工程会提示部分图片不存在，并跳过这些图片及其标注。

## 8. 导出

- **Excel Detail**：每条标注一行；列为 Depth、Item ID、Type、Judgment、Subtype/Remark、Test Subtype、Colour。
- **Excel Stats**：每个深度的类型计数与 Total。
- **Word Report(All)**：按深度分组的整图报告，图片保持全分辨率；每张图前有图片名/数量/ID 范围表。
- **Word Export Test**：按 MP / NoMP / Test 导出套索区域；Test 分 `Test-Label` / `Test-Unlabel` 两列，裁剪图保持原分辨率。

导出在后台线程执行，窗口会显示进度；完成后提示保存路径。若失败，会提示错误并写入日志。

**把导出用于快速分类：** 在 Excel Detail 中按 Type/Remark 筛选或分组，就能看到同一种未知颗粒在全批样品中的分布；再挑选代表去做确认检测。Word Report(All) 提供对应位置的全图上下文。
